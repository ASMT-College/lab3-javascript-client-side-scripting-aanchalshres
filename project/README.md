# Traveller's Diary Nepal 🌏🇳🇵

**Traveller's Diary Nepal** is a personal travel blog website dedicated to sharing unique travel stories, experiences, photos, and videos from across Nepal. The goal of this website is to serve as both a digital diary and a travel guide, providing honest recommendations and insights from real journeys.

## 📌 Features

- 🧳 Personal travel stories and blog posts
- 📸 Photo and video content from various destinations
- 🌄 Recommendations for places to visit, stay, and eat
- 🔎 Easy navigation and search by location or category
- 🗓️ Timeline of trips and experiences

## 🚀 Tech Stack

- **Frontend**: HTML, CSS, JavaScript
- **Backend**: PHP
- **Database**: MySQL
- **Media**: Embedded YouTube or self-hosted videos
- **Hosting**: Localhost

## 🎯 Purpose

The purpose of Traveller's Diary Nepal is to:
- Inspire travelers to explore Nepal.
- Provide authentic and personal travel recommendations.
- Document beautiful moments and discoveries in various regions of Nepal.
- Promote local culture, food, and hidden gems.
